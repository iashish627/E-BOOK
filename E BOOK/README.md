# E BOOK

Workspace for creating and publishing digital books.

## Projects

- `marketing/` — marketing research, strategy, and reference notes.
- `startup-opportunities/` — the 300 startup opportunities eBook.
- `website/` — storefront and landing-page source code.
- `assets/` — cover art, page backgrounds, previews, and other media.

## Working principles

- Keep source research and final reader-facing copy separate.
- Track sources and verify factual claims before publishing.
- Store only assets that are licensed or that we have permission to use.
